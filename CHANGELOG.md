# Changelog

## 0.2.3
- Replaced the drawn REDPILL header with the official RedPill logo artwork.
- Added a dedicated red-pill application icon for the title bar, tray and dialogs.
- Added an in-app scrolling Movement Log inspired by BluePill's console output.

- Keeps ACTIONS reset behavior when the process is stopped.

- Improved button visibility across Windows Look & Feel implementations.
